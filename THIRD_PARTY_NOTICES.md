# Third-party components

This package redistributes the Windows x64 loader files from the official BepInEx 5.4.23.5 release. Original copyright and license notices are included in `licenses/`.

- BepInEx and its integration components: https://github.com/BepInEx/BepInEx/tree/v5.4.23.5
- HarmonyX / Harmony compatibility assemblies: https://github.com/BepInEx/HarmonyX
- MonoMod.RuntimeDetour and MonoMod.Utils: https://github.com/MonoMod/MonoMod
- Mono.Cecil and associated symbol/utility assemblies: https://github.com/jbevain/cecil
- Unity Doorstop (`winhttp.dll`): https://github.com/NeighTools/UnityDoorstop

CELESTAY and Unity game assemblies are not redistributed. They remain part of the user's own game installation.
