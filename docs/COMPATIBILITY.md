# 兼容性与验证记录

本页区分实际游戏记录、模拟检查与尚未验证的场景。测试记录是有限样本，不构成成功率或长期稳定性保证。

## 当前版本

- 控制程序：0.2.4
- 游戏内插件：0.2.3
- 加载器：BepInEx 5.4.23.5 Windows x64
- 游戏环境：Windows 上的 64 位 Unity Mono 版本 CELESTAY
- 游戏兼容性由 `InstallerCore.GameHash` 校验，不能只修改该值来适配游戏更新

## 长时间运行与未复现反馈

旧插件 0.2.2 的一次长时间运行记录为 4,429 次尝试、4,428 次确认捕获、0 次记录失败、341 次完美；最后一竿结果未确认。运行因状态文件读写冲突停止，没有完成八小时。

0.2.3 已调整状态文件读写并通过相应回归检查，但尚未完成一次有完整记录的八小时验证。不要用旧运行记录宣称新版已通过八小时测试，也不要把停止后的累计计时当作实际钓鱼时长。

曾收到一次收竿后停止的反馈，随后同一测试者反馈恢复正常。具体弹窗、停止原因和触发条件尚未确认；当前不能将其归因为新图鉴，也不能声称已经修复。

锁屏、系统睡眠恢复、未匹配的游戏版本，以及不同电脑上的所有组合均未完整验证。
